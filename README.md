# NWN2 Module Toolkit

**Русский** | [English](README.en.md)

Локальный офлайн-инструмент для модулей **Neverwinter Nights 2**: он индексирует модуль,
анализирует его и открывает браузерный дашборд для всего, что утомительно делать руками —
ссылки, хаки, таблицы 2DA, локализация, кампании и карты мира.

Всё работает на вашей машине. Данные модулей никуда не отправляются.

---

## Что умеет

* **Анализ** — индексирует каждый ресурс модуля (или целой кампании) и показывает реальные
  проблемы: отсутствующие скрипты и диалоги, битые strref, блюпринты, на которые есть
  ссылки, но которых нет; устаревшие копии 2DA, небезопасные имена, дубликаты.
* **Дашборд** — одна локальная страница (`http://127.0.0.1:8765`) с вкладкой на каждую задачу,
  собранная из анализа выбранного модуля.
* **Хаки** — список, распаковка, чистка и пересборка `.hak`; сравнение копий, поиск дубликатов.
* **Редактор 2DA** — чтение, правка и проверка таблиц, сравнение с установленной игрой.
* **Локализация** — сколько текста несёт модуль и сколько уже переведено (журнал, диалоги,
  строки скриптов), плюс проверка глоссария: термины, разметка, подстановки, родовые формы.
* **Модуль в кампанию** — выполняет шаги редактора кампаний: создаёт `Campaigns/<имя>/`,
  переносит туда журнал, переключает `module.ifo` на кампанию, с копиями `.bak`.
* **Карта мира** — просмотр и правка `.wmp`: точки, иконки, размеры, координаты.
* **Ассистент** (необязательно) — панель чата, которая умеет читать локальный анализ
  и предлагать правки.

---

## Требования

* Windows (пути и запуск дашборда рассчитаны на него), Python 3.10+
* Никаких сторонних пакетов Python: только стандартная библиотека
* Необязательно: установленная NWN2 — для таблиц речи и сравнения с базовой игрой
* Необязательно: ключ API DeepSeek — только если нужен встроенный ассистент

## Быстрый старт

```
git clone <этот репозиторий>
cd nwn-module-toolkit-1.5.3-nwn2

python nwn_analyse.py "D:\Neverwinter Nights 2\modules\MyModule.mod"
python run_dashboard.py
```

Затем откройте `http://127.0.0.1:8765`.

Целая кампания тоже подходит — укажите папку кампании:

```
python nwn_analyse.py "D:\Neverwinter Nights 2\Campaigns\MyCampaign"
```

Результаты попадают в `nwn_workspace/<имя>/` (индекс, report.json, CSV-отчёты, диалоги).
Дашборд читает именно эти файлы.

## Ассистент (со своим ключом)

Ассистент необязателен и **выключен по умолчанию**. Если он нужен, положите ключ
в `nwn_workspace/harness.json`:

```json
{ "api_key": "<ваш ключ>" }
```

Важно:

* ключ читает только локальный сервер; в браузер он не передаётся и в экспорт отчётов не попадает;
* `harness.json` указан в `.gitignore` — не коммитьте его;
* без ключа остальной тулкит работает как обычно.

Если нужен обычный чат DeepSeek, на вкладке «Ассистент» есть ссылка
<https://chat.deepseek.com/> — она открывается в новой вкладке: сайт запрещает встраивание
в рамку, поэтому ссылка — честный способ его предложить.

---

## Данные и приватность

* `nwn_workspace/` хранит результаты анализа и **игнорируется гитом** — там могут быть имена
  файлов и тексты из модулей, которые вам не принадлежат.
* Ничего не покидает вашу машину, кроме необязательного запроса ассистента: в нём только
  ваш текст и краткая сводка открытого анализа.
* В репозитории нет ключей, токенов и учётных данных.

## Быстрый старт за три шага

1. Скачайте архив из [релиза v1.5.3-ru.1](https://github.com/mccellownick-cell/nwn-module-toolkit/releases/tag/v1.5.3-ru.1)
   (`nwn-module-toolkit-1.5.3-ru.1.zip`) и распакуйте в любую папку.
2. Запустите `install.bat` — он проверит Python и подготовит `nwn_workspace`.
3. Запустите `run_dashboard.bat` и откройте <http://127.0.0.1:8765>.

Анализ модуля из командной строки:

```
python nwn_analyse.py "D:\Neverwinter Nights 2\modules\МойМодуль.mod"
```

Подробнее — [INSTALL.md](INSTALL.md) и [docs/GUIDE.ru.md](docs/GUIDE.ru.md).
