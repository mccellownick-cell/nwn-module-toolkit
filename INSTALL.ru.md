# Установка NWN Module Toolkit

**Русский** | [English](INSTALL.md)

Тулкит не требует установки в привычном смысле: это набор скриптов на Python, который
работает из своей папки. Ниже — что нужно и как запустить.

---

## Что нужно

| Требование | Зачем |
|---|---|
| Windows 10 или 11 | пути и запускалки рассчитаны на неё |
| Python 3.10 или новее | сам тулкит; сторонние пакеты не нужны |
| Neverwinter Nights 2 (по желанию) | таблицы речи и сравнение с базовой игрой |
| NWNScriptCompiler (по желанию) | компиляция `.nss` в `.ncs`; кладётся в `tools\` |

Проверить Python:

```
python --version
```

Должно быть 3.10 или выше. Если команда не найдена — установите Python с python.org
и включите «Add Python to PATH».

---

## Шаги

1. Скопируйте папку тулкита в удобное место, например `D:\Tools\nwn-module-toolkit`.
   Кириллица в пути допустима, но латиница надёжнее.
2. Откройте терминал в этой папке.
3. Проанализируйте модуль:

   ```
   python nwn_analyse.py "D:\Neverwinter Nights 2\modules\MyModule.mod"
   ```

4. Запустите дашборд:

   ```
   python run_dashboard.py
   ```

5. Откройте `http://127.0.0.1:8765` в браузере.

То же самое двойным щелчком: `run_dashboard.bat` — запуск дашборда,
`analyse_vhc.bat` — анализ Vordan's Hero Creator.

---

## Кампания вместо модуля

Укажите папку кампании — тулкит разберёт все входящие в неё модули и общий журнал:

```
python nwn_analyse.py "D:\Neverwinter Nights 2\Campaigns\MyCampaign"
```

---

## Где лежат результаты

```
nwn_workspace\<имя>\        индекс, report.json, CSV-отчёты, диалоги
```

Эта папка **игнорируется гитом**: там могут быть имена файлов и тексты из чужих модулей.
Её можно удалить в любой момент — следующий анализ создаст её заново.

---

## Компилятор скриптов (по желанию)

Игра исполняет только `.ncs`. Если хотите компилировать скрипты из тулкита, положите
`NWNScriptCompiler.exe` в папку `tools\` и укажите путь в настройках дашборда
(вкладка «Настройки»). Без компилятора всё остальное работает.

---

## Ассистент (по желанию)

Ключ API кладётся в `nwn_workspace\harness.json`:

```json
{ "api_key": "<ваш ключ>" }
```

Файл указан в `.gitignore` — не коммитьте его. Без ключа ассистент просто выключен.

---

## Обновление

Распакованные файлы тулкита можно заменить новыми, сохранив `nwn_workspace\` —
там ваши настройки, глоссарий и ключ.

---

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `python` не найден | Python не в PATH; переустановите с галочкой «Add to PATH» |
| порт 8765 занят | закройте прошлый запуск дашборда |
| модуль не читается | путь в кавычках, файл существует, это `.mod` или `.erf` |
| пустой отчёт | модуль без ресурсов, либо указан не тот файл |
